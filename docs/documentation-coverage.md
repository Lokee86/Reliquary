# Documentation Coverage

Parent index: [Documentation index](INDEX.md)

## Purpose

This document maps implemented code boundaries to their canonical documentation owners.

## Overview

Only implemented code belongs in this matrix. Future-only product/runtime work is owned by [Roadmap](roadmap.md) and is intentionally excluded until concrete implementation roots exist.

## Activity-clock test boundary

`src/archive/archive_activity_measurement_tests.rs` supplies bounded fixture/reference-ledger verification and informational timing/memory measurements; [Development](development.md) owns its invocation and measurement limits, and [the activity-clock plan](rel-activity-clock-implementation-plan.md) records results.

The Archive projection, historical read API and synced canonical runtime receipts are implemented through Phase 1.6 with post-reopen topology preservation gates. `tests/rel_activity_clock_contract.rs` verifies the reference-ledger/recovery contract. [The REL activity-clock plan](rel-activity-clock-implementation-plan.md), [behavioral contracts](behavioral-contracts.md) and [current limitations](current-limitations.md) record implemented runtime receipts, post-reopen topology preservation gates and recorded fixture measurements and verification exceptions. `src/archive/archive_activity_preservation_tests.rs` covers physical repacks, migration and reconciliation through Archive-owned comparisons; the existing facade operation owners enforce those comparisons.
