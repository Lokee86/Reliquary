# Same-REL Perception acceptance

Parent index: [Acceptance evidence](./INDEX.md)

## Purpose

Verify the complete Perception lifecycle through an authorized mounted REL and preserve the evidence for the tested native decision contracts.

## Overview

The mounted fixture passed in 7.99 seconds with scripted general, embedding and native decision endpoints. It used a disposable native REL with accepted Archive activity, direct Memories and settled Dream work. Gateway ran the managed worker and reopened the same owner file between processing windows.
