# Import step 24 attribution acceptance

## Purpose

Record epoch-scoped cohort and evidence construction on `integrate/import-freshness-settlements-20261017`. Step 25 owns incremental settlement persistence and authenticated replay; completion and scoped worker admission remain later steps.

## Overview

The private owner freeze builds a manifest for the current durable ImportStart. Exact receipt source Nodes and complete Import Episodes prove first-publication births. The physical pre-start Freshness replay supplies the existing recipient population and preserves its records. Existing recipient body, revision, lifecycle and provenance remain proof inputs rather than imported births.

Pre-start tombstones remain in canonical Freshness history and exclusion proof. Their existing retention descriptors authenticate terminal coordinates and retained revision identities without an active-Memory read. They are absent from event targets, graph traversal and result records; rejection, reopen and retained historical reads preserve terminal lifecycle.

Source records, semantic fragments and Dream sources are restricted to the epoch. Graph, community and vector target proofs use the explicitly validated recipient population. The result set contains only epoch births, recipients of exact provisional import events and recipients selected by planned historical propagation. Full recipient context is separate from result attribution.

Freshness event selection scans a finite physical start/freeze interval, retains only candidate identities and effects, then removes identities already accepted before the start marker. Same-activity-cut receipts are distinguished physically; cache growth and later frames cannot expand a frozen result. Mixed import/external fragment source evidence rejects.
